## ▶️ How to Run Programs

### 1. C Programs

Install a C compiler such as GCC.

```bash
gcc program.c -o program
```

Run on Windows:

```bash
program.exe
```

### 2. C++ Programs

Install a C++ compiler such as G++.

```bash
g++ program.cpp -o program
```

Run:

```bash
program.exe
```

### 3. C# Programs

Install the .NET SDK.

For an existing .NET project:

```bash
dotnet run
```

For a standalone C# file, if the C# compiler is configured:

```bash
csc Program.cs
Program.exe
```

### 4. Java Programs

Install the JDK and configure Java in PATH.

```bash
javac Main.java
java Main
```

The public class name and filename must match. Replace `Main` with your actual class name.

### 5. JavaScript Programs

Install Node.js.

```bash
node program.js
```

### 6. Python Programs

Install Python and configure it in PATH.

```bash
python program.py
```

If `python` does not work, try:

```bash
py program.py
```

### 7. PHP Programs

Install PHP and configure it in PATH.

```bash
php program.php
```

### 8. HTML, CSS and JavaScript Projects

Open `index.html` in a web browser.

You can also open the project folder in Visual Studio Code and use the Live Server extension.

**Note:** CSS and browser-side JavaScript are generally executed by the browser. Node.js is used for JavaScript programs that run outside the browser.
